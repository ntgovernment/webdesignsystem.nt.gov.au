Table Component

The Table component provides structured, accessible data presentation with support for headers, striped rows, hover states, and sortable columns. Imported from @ntgovernment/web-design-system.

A simple table with headers and data rows.

Terminology
Description
Palettes Palettes define the available colour values in the system. Palettes contain raw colour values (hex or RGBA). They do not define usage. Designers and developers should not apply palette values directly in components.
Base value Base value is the specific attribute, such as hex or rgba code applied to a primitive token through theme.
Tokens Tokens assign semantic meaning to the colours from the palette based on their use cases e.g. $ntg-clr-bg-default, $ntg-clr-text-default.
Components Components consume tokens to apply colour consistently in the interface.
Themes Themes control which palette values are assigned to tokens. Themes allow colour values to change without altering token names or component logic.
