Tab Component

Organize content into sections with sticky tab navigation. Navigation appears when 2+ tabs are detected.

How it works: The Tab component scans for .nt-tab-marker elements with data-tab-title attributes. Content after each marker is grouped into that tab's panel. When more than 1 tab is found, a sticky navigation is generated.

Features

The Tab component provides a powerful way to organize complex content:

Automatic Detection

Simply add .nt-tab-marker elements with data-tab-title attributes throughout your content. The component automatically detects them and creates the navigation.

Sticky Navigation

Tab navigation sticks below the header as you scroll, ensuring users can always switch between sections. The sticky offset is configurable via CSS variables or data attributes.

Keyboard Accessible

Full keyboard support with Arrow keys for navigation and Home/End for jumping to first/last tabs. Follows W3C ARIA tabs pattern.

Smart Rendering

When only a single tab is detected, the navigation is automatically hidden to maintain a clean, simple layout.

Usage Guide

Implementing tabs in your page is straightforward:

Step 1: Add a container element with data-tab-container attribute
Step 2: Insert <div class="nt-tab-marker" data-tab-title="Your Title"></div> where you want each tab to start
Step 3: Add your content after each marker. Everything until the next marker (or end of container) belongs to that tab

The component will automatically initialize on page load and create the tab navigation.

Example 4: Single Tab (No Navigation)

With only 1 tab, navigation is hidden automatically.

Single Tab Content

When only a single tab is detected, the component smartly hides the tab navigation to maintain a clean layout. There's no need for tab switching UI in this case.

This is useful when you have a template that may sometimes have multiple tabs, but in certain cases only has one section of content.

Notice there's no tab navigation above this content because only one tab exists.
