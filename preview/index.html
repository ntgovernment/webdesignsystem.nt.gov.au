Welcome to the NT Design System

This is a preview of the design system with all major components integrated. You're seeing the header, left navigation, and theme switcher working together.

🎨 What You're Seeing

This page demonstrates:

  • Header Component - NT Government branding at the top
  • Left Navigation - Collapsible sidebar with 2-level menu structure
  • Theme Switcher - Toggle between light and dark themes (top right)
  • Responsive Layout - Try resizing your browser to see mobile behavior

🚀 Getting Started

All components are built with vanilla JavaScript - no framework dependencies!

Key Features:

  • Auto-mount functionality via data attributes
  • Small bundle sizes (1-8 KB per component)
  • Keyboard accessible and ARIA compliant
  • Theme persistence with localStorage
  • Mobile-responsive with smooth transitions

Try These Interactions:

  • Click sections in the left navigation to expand/collapse
  • Toggle the theme switcher (top right) to see dark mode
  • Resize your browser to see the mobile drawer menu
  • Use Tab key to navigate through interactive elements
