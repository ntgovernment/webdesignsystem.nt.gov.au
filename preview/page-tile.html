Features

  • Fully responsive grid layout with --sp-xxl (32px) spacing
  • Accessible semantics with ARIA roles (list, listitem)
  • Hover states with subtle shadow and border color transitions
  • Focus-visible ring styling for keyboard navigation (orange #FFAB00)
  • Flexible content area for text-based tiles
  • Clickable tile support with full-sized link areas
