PageCard Component

Display lists of ContentPage assets as a responsive grid using Card-style layout with Image and Title. This component is optimized for Squiz DXP deployment with server-side rendering and client-side hydration.

📋 Component Features

  • Responsive Grid Layout - Auto-fits columns (1-6) based on container width
  • Card-Style Display - Image (16:9), Title, optional Description
  • ContentPage Assets - Direct support for content page data
  • Clickable Cards - Entire card acts as link with keyboard support
  • No Images Fallback - Placeholder icon when image URL not provided
  • Accessibility - WCAG AAA compliant with keyboard navigation and ARIA labels
  • Design Tokens - Integrates with NT Design System tokens
  • Server/Client Hydration - Minimal HTML + async rendering

📝 Input Schema

The component accepts an array of PageArray items:

{
    "PageArray": [
        {
            "PageAsset": { "url": "/path/to/page" },
            "CardImage": { "url": "https://..." },
            "CardTitle": "Card title"
        }
    ]
}

✨ Design Features

  • 16:9 aspect ratio images (responsive cover fill)
  • 2-line text clamp for descriptions
  • Hover effects with shadow enhancement
  • Focus indicators for keyboard navigation
  • Placeholder icon for missing images
  • Mobile-responsive breakpoints
  • High contrast mode support
  • Reduced motion preference respect

🚀 Squiz DXP Integration

Installation:

  1. Register component with DXP service endpoint
  2. Manifest schema (manifest.json) defines input validation
  3. Server renders minimal HTML with data-hydration-props
  4. Client-side JS auto-initializes and renders full grid

Nester Integration:

<div data-hydration-component="page-card" 
     data-hydration-props='{...}'></div>

<script src="page-card-client.js"></script>

ContentPage Asset Mapping:

The component accepts any data source that provides objects with:

  • id - Asset ID or unique identifier
  • title - Asset name or display title
  • imageUrl - Asset image URL or thumbnail
  • description - Asset summary metadata
  • href - Asset URL or detail page link

♿ Accessibility

  • Semantic HTML5 - Uses proper heading tags (h3), links (a), and divs
  • Keyboard Navigation - Tab through cards, Enter/Space to activate
  • ARIA Labels - Included on links for screen reader context
  • Focus Indicators - Theme-specific 4px shadow (orange NTG)
  • Image Alt Text - All images have descriptive alt text
  • Color Contrast - WCAG AAA ratio (7:1) for all text
  • High Contrast Mode - Proper display in Windows High Contrast
  • Reduced Motion - Respects prefers-reduced-motion setting
