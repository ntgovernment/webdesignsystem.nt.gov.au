🎨 Theme Switcher Component

DXP Component Service - Multi-URL theme switcher with tab navigation

Example 1: Single Theme (No Tabs)

When only one theme is provided, no tabs are shown - just the iframe.

Example 2: Two Themes

With two themes, tab navigation appears above the iframe content.

Example 3: Three Themes (Maximum)

Maximum of 3 themes supported with tab navigation.

📖 Usage

Server-side rendering with client-side hydration pattern:

<div 
  data-hydration-component="theme-switcher" 
  data-hydration-props='{
    "themes": [
      {"name": "Light", "url": "https://..."},
      {"name": "Dark", "url": "https://..."}
    ],
    "height": "600px",
    "defaultTheme": "Light"
  }'>
</div>
Props:
  • themes (required): Array of 1-3 theme objects with name and url
  • height (optional): Iframe height, default "600px"
  • defaultTheme (optional): Name of theme to show by default
